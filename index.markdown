# Análisis de Flujo de Datos Simulado con Spark y Jekyll

Este proyecto demuestra cómo procesar y analizar un flujo de clics simulado utilizando Python y Spark, generar estadísticas agregadas por usuario y visualizar los resultados mediante gráficos de barras. Además, integra el análisis en un blog estático con Jekyll y GitHub Pages, mostrando cómo combinar procesamiento de datos y presentación web.
## Objetivo
Aplicar técnicas de analítica avanzada para procesar y visualizar un flujo de datos simulado en un contexto empresarial, con el fin de identificar patrones de comportamiento de los usuarios, como la frecuencia y distribución de clics, apoyar la toma de decisiones estratégicas, y evaluar enfoques de procesamiento por lotes y en tiempo real.

## Reflexión
El procesamiento en streaming permite identificar patrones y eventos en tiempo real, facilitando una respuesta inmediata, mientras que el procesamiento por lotes analiza datos históricos para generar informes y análisis agregados, aportando una visión completa a largo plazo.
